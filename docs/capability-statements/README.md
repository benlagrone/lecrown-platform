# Capability Statements

This folder stores working drafts for one-page capability statements.

Capability statements are reusable bid-readiness documents. Each company should
have one master statement and buyer-specific versions where the audience or
commodity codes differ.

Track each statement in `data/capability-statements.csv`, then map the finished
file to storage in `data/document-portal-map.csv`.

## Drafting Rules

- Do not claim certifications until the certification is approved.
- Do not invent past performance. Use `TBD` until references are confirmed.
- Keep owner financials, tax details, and private records out of the statement.
- Keep one master markdown source, then export a PDF for portal uploads.
- Store portal IDs in `data/document-portal-map.csv`; do not paste private
  document URLs into public tracker files.

## Required Inputs

- Legal company name and DBA.
- Primary contact name, email, phone, and website.
- Confirmed core services.
- NAICS and NIGP commodity codes.
- Approved certifications and active registrations.
- Differentiators that can be defended.
- Past performance references or project examples.
- Service geography.
